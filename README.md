# 一恒体系 · 命理 / 占卜 / 中医调理

**线上地址：https://qin-zhi-peng.github.io/gzli/**

一个总领首页 + 三个可以点进去就用的板块，全部纯静态：HTML + CSS + JS，浏览器内自算，
不依赖服务端、不上传任何输入。手机打开即用。

> 本站为传统文化研究与个人兴趣展示，**不构成医疗建议，不诊断、不开方**。
> 中医部分仅供健康参考，身体不适请及时就医。完整条款见 [LICENSE](LICENSE)。

## 首页形态（2026-11-01 用户定）

- 顶部只放**官方头像 + 一恒体系字标**，不做印章、不做倾斜（头像摆正）。
- 不放大段介绍、不放开场文案、不放「本地推算/不上传」标签条、不放常见问题。
- 只留三个入口卡：图标 + 板块名 + 一句话。
- **微信引导只在各板块的详细报告底部出现**（命理摘要下 / 起卦后卦盘下 / 辨证结果下）。

## 口径与边界

- 命理：新修干支历法（360 日岁序 + 平气月）＋ 紫微斗数新修体系；数据包覆盖 1900–2100。
- 占卜：排盘与本地引擎逐字段对拍（随机 + 边界共 900+ 组、11 万字段，差异 0）；起卦时间固定 UTC+8。
- 中医：症状按权重指向证型，只在浏览器内做倾向判断；**不含方剂与剂量**，只给辨证方向与日常调护。
- 三板块成品一律不标来源，只署「一恒体系」。
